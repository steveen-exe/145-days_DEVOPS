**Change Ownership_**
chmod -> modify the owner of a file
syntax: --- chown [OPTIONS] [NEW_OWNER][:[NEW_GROUP]] FILENAME

ex1 : change only user -
     chown john file.txt
ex2. change user and group -
     chown user:group file.txt
ex3. change only group
     chmod :group FILENAME
recressive folder ->
     sudo chown -R john:developers /workspaces/my_project/
