nice and renice control process priority — how much CPU time a process gets relative to others.
Priority Scale
- Range: -20 to +19
- -20 = highest priority (gets CPU first)
- +19 = lowest priority (gets CPU last)
- Default = 0
nice — Set priority when starting a process

nice python3 script.py           # start with default nice value (+10)
nice -n 10 python3 script.py     # start with priority +10 (low priority)
nice -n -10 python3 script.py    # start with priority -10 (high priority, needs root)

▎ Only root can set negative nice values.

---
renice — Change priority of an already running process

renice -n 10 -p 1234         # set PID 1234 to priority +10
renice -n -5 -p 1234         # set PID 1234 to -5 (needs root)
renice -n 15 -u steve        # lower priority for ALL of steve's processes
renice -n 10 -g groupname    # apply to entire process group
