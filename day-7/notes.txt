>Journalctl : This is the most useful command for production debugging using logs.
    journalctl - view all the logs
    -journalctl -n 50 #last 50 logs
    -journalctl -f #follow logs 
    -journalctl -u ssh #show logs of a specefic service
    -journalctl --since today
    -journalctl --since "1 hour ago"
    -journalctl -p err
